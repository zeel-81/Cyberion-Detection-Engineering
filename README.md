# Cyberion ThreatShield

Cyberion ThreatShield is a detection engineering and threat hunting project focused on Windows security telemetry, Sigma detection rules, MITRE ATT&CK coverage, incident investigation, IOC research, and incident response playbooks.

## Deliverables

- 15+ Sigma detection rules
- MITRE ATT&CK coverage matrix
- Correlation-style detection rules
- 2+ threat hunts
- 2+ incident investigations
- IOC research
- 3+ incident response playbooks
- False-positive review
- Detection methodology
- Executive summary
- Final presentation

## Validation

Detection rules were validated against Windows EVTX telemetry.

## Repository Structure

- `rules/` — Sigma rules and tests
- `coverage/` — ATT&CK coverage
- `hunts/` — Threat hunting
- `incidents/` — Incident investigations
- `ioc-research/` — IOC research
- `playbooks/` — Response playbooks
- `methodology/` — Methodology and data dictionary
- `reports/` — Reports and analysis
- `presentation/` — Final presentation
